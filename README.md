# 📚 KichoBot — Бот расписания КарГУ Букетова

**KichoBot** — современный и быстрый Telegram-бот для студентов и преподавателей Карагандинского университета имени академика Е.А. Букетова (КарГУ / Buketov University).

Бот предоставляет актуальное расписание занятий групп и преподавателей, расписание сессии, удобную навигацию, быстрый поиск и систему кэширования для работы даже при сбоях или недоступности университетского портала.

---

## 🚀 Основные возможности

- 👥 **Расписание студентов:** Просмотр расписания по факультетам, специальностям и группам.
- 👨‍🏫 **Расписание преподавателей:** Поиск по кафедрам и преподавателям.
- ⚡ **Быстрый поиск:** Поиск групп (`Г ВТ-21-1`) и преподавателей (`П Иванов`) в чате.
- 🌐 **Двуязычность:** Полная поддержка русского и казахского языков (RU / KZ).
- 🛡 **Надёжность и кэширование:** Автоматическое сохранение расписаний в MongoDB — расписание доступно даже при падении портала университета.
- 🟢 **Индикация актуальности:** Цветовые индикаторы свежести данных (до 5 часов, до 24 часов, более суток).
- 🔒 **Защита от спама и атак:** Многоуровневый шлюз безопасности, фильтрация медиа-спама и ограничение частоты запросов.
- 🔄 **Автоматическая синхронизация:** Ежедневный фоновый сбор и обновление списков факультетов, программ, групп и преподавателей.

---

## 🛠 Технологический стек

- **Среда выполнения:** Node.js 20.x (ES Modules)
- **Фреймворк:** Express.js (REST API, Webhook endpoints, Health Check)
- **Telegram API:** `node-telegram-bot-api`
- **База данных:** MongoDB (Mongoose ODM)
- **Парсинг данных:** Axios + Cheerio (быстрый HTTP-клиент с управлением сессиями и куками)
- **Логирование:** Winston (консоль, файлы с ротацией, MongoDB, уведомления в Telegram)
- **Интернационализация:** i18next
- **Планировщик задач:** node-cron

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Kich0/kichobot67.git
cd kichobot67
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните переменные в `.env`:
- `PORT` — порт сервера (по умолчанию `5000`).
- `DB_URI` — строка подключения к MongoDB (`mongodb://localhost:27017/kichobot` или MongoDB Atlas).
- `TG_TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather).
- `BOT_ID` — ID бота.
- `LOG_CHANEL_ID` — ID Telegram-канала/чата для системных логов и ошибок.
- `LOGGER_TG_TOKEN` — токен логгер-бота (может совпадать с `TG_TOKEN`).
- `KSU_DOMAIN` — домен портала университета (по умолчанию `https://schedule.buketov.edu.kz`).
- `KSU_LOGIN` / `KSU_PASSWORD` — логин и пароль для доступа к расписанию портала.
- `BOT_MODE` — режим работы бота: `polling` (для разработки) или `webhook` (для продакшена).

### 4. Запуск приложения

**Режим разработки:**
```bash
npm run dev
```

**Продакшен запуск:**
```bash
npm start
```

**Первоначальная синхронизация базы данных:**
```bash
node update_db.js
```

## ☁️ Развёртывание на Render

Проект оптимизирован для работы в едином контейнере на **Render** через конфигурационный файл [`render.yaml`](render.yaml):
- Сервер Express и Telegram-бот запускаются в рамках **одного процесса** (`server.js`), что позволяет оставаться в пределах лимитов оперативной памяти (512 MB).
- Для продакшена рекомендуется установить `BOT_MODE=webhook`, `WEBHOOK_DOMAIN=https://your-app.onrender.com` и `USE_FREE_PROXIES=true` при необходимости обхода геоблокировок.

## 📂 Структура проекта

```
├── bot/                  # Исходный код Telegram-бота
│   ├── controllers/      # Контроллеры расписания, профиля и команд
│   ├── handlers/         # Обработчики сообщений, кнопок и команд
│   ├── middlewares/      # Защита от спама, шлюз безопасности, проверка прав
│   ├── models/           # Mongoose-схемы (User, Group, Faculty, Schedule и др.)
│   ├── services/         # Сервисы взаимодействия с базой данных
│   ├── cron/             # Фоновые cron-задачи (ежедневное обновление, прогрев кэша)
│   └── locales/          # Переводы интерфейса (ru.json, kz.json)
├── backend/              # Бэкенд API и модули парсинга портала
│   ├── controllers/      # Контроллеры API и резервного браузера
│   ├── services/         # KsuAuthService, ScheduleService, FreeProxyService
│   └── routers/          # Маршрутизация Express API
├── config.js             # Единая валидация переменных окружения
├── botInstance.js        # Инициализация общего экземпляра бота
├── server.js             # Главная точка входа (Unified Server)
├── update_db.js          # Скрипт полной синхронизации БД
└── render.yaml           # Конфигурация деплоя на Render
```
